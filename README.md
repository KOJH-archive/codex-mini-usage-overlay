# Codex Mini Usage Overlay

Unofficial Windows overlay that shows your Codex usage next to the Codex/ChatGPT MINI window.

```text
5h 72% (2h 14m) · W 41% (3d 8h)
```

The overlay displays remaining Codex quota for the 5-hour and weekly windows, plus the time left until each reset. It uses the local Codex App Server through your existing signed-in Codex desktop/CLI session, so you do not enter or store an API key.

> This is not an official OpenAI product.

## Features

- Shows Codex usage, remaining quota, and reset time near the MINI window
- Reuses your existing Codex login session
- No password or API key storage
- Starts automatically with Windows after install
- Appears only when a Codex/ChatGPT MINI-like window is visible
- Keeps the display above the Windows taskbar
- `off` button to disable the overlay
- Left-click to expand details
- Right-click to close for the current run
- Warning and critical color states for low remaining quota
- Graceful fallback when usage cannot be read

## Requirements

- Windows 10 or 11
- Node.js 20+
- Codex desktop app or Codex CLI signed in on the same Windows account

## Install

Download or clone this repository, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-CodexMiniUsageStartup.ps1
```

After installation, the overlay starts automatically when you sign in to Windows. It stays hidden until the Codex/ChatGPT MINI window is visible.

## Run Manually

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-CodexMiniUsage.ps1
```

Optional refresh interval:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-CodexMiniUsage.ps1 -RefreshSeconds 30
```

Force it to stay visible even when MINI is not detected:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-CodexMiniUsage.ps1 -AlwaysVisible
```

## Disable and Re-enable

Click the `off` button in the overlay to disable it.

To enable it again:

```powershell
powershell -ExecutionPolicy Bypass -File .\Enable-CodexMiniUsage.ps1
```

## Uninstall

```powershell
powershell -ExecutionPolicy Bypass -File .\Uninstall-CodexMiniUsageStartup.ps1
```

## How It Works

`codex-mini-usage-agent.mjs` starts the local Codex App Server over stdio and calls:

```text
account/rateLimits/read
```

`Start-CodexMiniUsage.ps1` renders a small Windows Forms overlay from the status JSON generated by the agent.

The displayed quota windows depend on the account and response returned by Codex. In the current format:

- `5h`: remaining percentage in the rolling 5-hour Codex quota window
- `W`: remaining percentage in the weekly Codex quota window
- Parentheses: time until that quota window resets
