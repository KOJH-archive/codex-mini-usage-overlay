## First Release Title

`v0.1.0 - Codex MINI usage overlay for Windows`

## First Release Notes

```markdown
Initial release.

Features:

- Shows Codex 5-hour and weekly remaining usage
- Shows reset countdowns in the format `5h 72% (2h 14m) · W 41% (3d 8h)`
- Reuses the existing local Codex login session
- No API key or password storage
- Appears near the Codex/ChatGPT MINI window
- Keeps the overlay above the Windows taskbar
- Includes Windows startup install, enable, and uninstall scripts
- Includes an `off` button for disabling the overlay

This is an unofficial community tool and is not affiliated with OpenAI.
```
